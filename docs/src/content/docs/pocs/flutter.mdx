## Objectives

- Evaluate Flutter for building a scalable mobile application dedicated to member engagement and association activities
- Test a modular widget system aligned with feature-based components for associations
- Implement a calendar feature to manage and display association events and activities

## Scope

This POC focuses on the mobile application.
The web application remains based on the existing web stack to optimize SEO, performance, and architectural alignment.

## Architecture Overview

- **Mobile framework:** Flutter (Android)
- **Widget system:** Feature-based modular widgets
- **Calendar module:** Event management and visualization

The widget system enables dynamic UI composition, where each widget corresponds to a specific association feature (events, membership, notifications, etc.).

## Findings

**Strengths**

- Fast UI iteration with Hot Reload
- Strong design consistency across platforms
- Good performance for dynamic widget rendering
- Modular architecture suitable for feature expansion

**Limitations**

- Initial project setup complexity
- Learning curve for team adoption
- Mobile-specific optimization required

## Conclusion

Flutter has been validated as a strong candidate for the mobile application.

It enables rapid feature development.

The web application remains on the existing stack to maximize performance and strategic alignment.

## Impact

- Dedicated mobile experience for association members
- Modular feature system improving maintainability
- Clear separation between web administration and mobile engagement
- Faster iteration on mobile features

### 2. Prototyping (Deployment Guide)
<Steps>
1.  **Directory Structure Setup**
    You will need to set up a dot env file to store your nextCloud credentials and API endpoint.
    ```sh
    NEXTCLOUD_DB_NAME=my_app
    NEXTCLOUD_DB_USER=my_app_user
    NEXTCLOUD_DB_PASSWORD=my_app_password

    ROOT_PWD=rootpassword

    MYSQL_HST=db
    MYSQL_DB=my_app
    MYSQL_USR=my_app_user
    MYSQL_PWD=my_app_password

    APP_PORT=3306
    APP_NAME=my_app
    ```

    For development, you should install go dependencies:

    ```sh
    github.com/go-sql-driver/mysql
    github.com/lib/pq
    github.com/go-chi/chi/v5
    ```

2.  **Compose Configuration**
    We use mariadb for both nextCloud and our Golang app.

    <Aside type="note" title="Security Tip">
      In this POC, we use environment variables for passwords.
    </Aside>

    ```yaml
    services:
      db:
        image: mariadb:10.11
        restart: always
        env_file:
          - .env
        environment:
          - MYSQL_ROOT_PASSWORD=${ROOT_PWD}
          - MYSQL_DATABASE=${MYSQL_DB}
          - MYSQL_USER=${MYSQL_USR}
          - MYSQL_PASSWORD=${MYSQL_PWD}
        volumes:
          - ./data/db:/var/lib/mysql

      redis:
        image: redis:alpine
        restart: always

      nextcloud:
        image: nextcloud:latest
        restart: always
        ports:
          - "8080:80"
        depends_on:
          - db
          - redis
        env_file:
          - .env
        environment:
          - MYSQL_HOST=${MYSQL_HST}
          - MYSQL_DATABASE=${MYSQL_DB}
          - MYSQL_USER=${MYSQL_USR}
          - MYSQL_PASSWORD=${MYSQL_PWD}
          - REDIS_HOST=redis
        volumes:
          - ./data/nextcloud:/var/www/html

      myapp:
        build: .
        restart: always
        ports:
          - "8000:5173"
        depends_on:
          - db
        env_file:
          - .env
        environment:
          - DB_USER=${MYSQL_USR}
          - DB_PASS=${MYSQL_PWD}
          - DB_HOST=${MYSQL_HST}
          - DB_PORT=${APP_PORT}
          - DB_NAME=${APP_NAME}
    ```

3.  **Initialization**
    run manually:
    ```bash
    # Start the docker images
    docker compose up --build
    ```

4.  **Shutdown**
    run manually:
    ```bash
    # Stop the docker images
    docker compose down
    ```
</Steps>

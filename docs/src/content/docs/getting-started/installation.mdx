## Clone the Repository

```bash
git clone https://github.com/AssoCORE/AssoCORE.git
cd AssoCORE
```

## Quick Start with Docker

The fastest way to get started is using Docker Compose:

<Steps>
1. **Start all services**

   ```bash
   docker-compose up -d
   ```

2. **View logs**

   ```bash
   docker-compose logs -f api
   ```

3. **Stop services when done**

   ```bash
   docker-compose down
   ```
</Steps>

<Aside type="tip" title="API Access">
  The API will be available at:
  - API: <http://localhost:8000>
  - API Documentation: <http://localhost:8000/docs>
  - Alternative Docs: <http://localhost:8000/redoc>
</Aside>

## Local Development Setup

For active development, you may prefer running services locally:

<Tabs>
  <TabItem label="1. Backend Setup">
    ```bash
    cd backend

    # Install dependencies with Poetry
    poetry install

    # Or with pip
    pip install -r requirements.txt

    # Copy environment configuration
    cp .env.example .env

    # Edit .env with your settings
    nano .env
    ```

    <Aside>
      Poetry is recommended for dependency management and virtual environment handling.
    </Aside>
  </TabItem>

  <TabItem label="2. Database Setup">
    Start PostgreSQL with Docker:

    ```bash
    docker run -d \
      --name assocore-db \
      -e POSTGRES_DB=assocore \
      -e POSTGRES_USER=assocore \
      -e POSTGRES_PASSWORD=dev_password \
      -p 5432:5432 \
      postgres:15-alpine
    ```

    Run database migrations:

    ```bash
    # With Poetry
    poetry run alembic upgrade head

    # Or directly
    alembic upgrade head
    ```
  </TabItem>

  <TabItem label="3. Run the API">
    ```bash
    # Development mode with hot reload
    poetry run uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

    # Or
    uvicorn app.main:app --reload
    ```

    <Aside type="tip">
      Hot reload automatically restarts when you change code!
    </Aside>
  </TabItem>
</Tabs>

## Environment Configuration

Create a `.env` file in the backend directory:

```bash title="backend/.env"
# Database
DATABASE_URL=postgresql://assocore:dev_password@localhost:5432/assocore

# Security
SECRET_KEY=your-secret-key-change-in-production
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=30

# Application
DEBUG=True
API_V1_PREFIX=/api/v1
PROJECT_NAME=AssoCORE

# CORS
BACKEND_CORS_ORIGINS=["http://localhost:3000","http://localhost:8000"]
```

<Aside type="caution" title="Security Warning">
  Never commit your `.env` file! Always change the `SECRET_KEY` in production.
</Aside>

## Troubleshooting

<Tabs>
  <TabItem label="Port in Use">
    If port 8000 is already in use:

    ```bash
    # Find process using port
    lsof -i :8000

    # Kill the process
    kill -9 <PID>

    # Or use a different port
    uvicorn app.main:app --reload --port 8001
    ```
  </TabItem>

  <TabItem label="Database Issues">
    ```bash
    # Check if PostgreSQL is running
    docker ps | grep postgres

    # View database logs
    docker logs assocore-db

    # Restart database
    docker restart assocore-db
    ```

    <Aside type="note">
      Make sure the database credentials in your `.env` match the Docker container settings.
    </Aside>
  </TabItem>

  <TabItem label="Poetry Issues">
    ```bash
    # Clear Poetry cache
    poetry cache clear . --all

    # Reinstall dependencies
    rm poetry.lock
    poetry install
    ```

    <Aside>
      If you continue having issues, try removing the virtual environment and reinstalling.
    </Aside>
  </TabItem>
</Tabs>
